ReelRadar

A directory of South African fishing waters, for fishermen, by a fellow fisherman.

Each spot shows its location, fish species, best time to go, live weather with a 7-day forecast, prices, contacts, crocodile and hippo warnings, places to stay and nearby tackle shops. Anglers log personal bests with a photo of the catch and talk in the forum.

  • Zero-dependency Java 21: one jar, plain JDK, with its own HTTP routing and OpenAPI 3.1 spec.
  • Lambda + SnapStart behind a function URL that only answers CloudFront (shared-secret header).
  • DynamoDB for records, S3 for photos served straight from the edge, with cache purges when a photo is removed.
  • Push-to-deploy with GitHub Actions, a least-privilege OIDC role and CloudFormation change sets.

03 Under the hood

You're inside one of my systems right now.

This page is a serverless app. Below is the path your request just took, with the edge location that actually served you highlighted.

  • Edge first. CloudFront terminates TLS, redirects www to the root domain with a CloudFront Function, and adds HSTS and frame, content-type and referrer headers.
  • No public bucket. Only the distribution can read S3, through Origin Access Control.
  • Concurrency-safe counter. One atomic DynamoDB ADD per visit, so visits that arrive at the same time are all counted.
  • Same origin. The API sits under /api/* on the same domain, so no CORS is needed.
  • Keyless CI/CD. GitHub Actions assumes an IAM role through OIDC, and CDK in Java 21 deploys it.

04 How I engineer

Rules I build by.

// 01

Design the failure path first

Redelivery limits, poison messages and dead-letter queues get designed before the happy path. That boundary is where systems break.

// 02

Correctness where money moves

Idempotency keys, atomic settlement, double-entry ledgers and pessimistic locks. Being fast doesn't help if the money is wrong.

// 03

Measure, don't guess

Benchmark the alternatives, read the heap dump, profile the threads. Performance claims need evidence behind them.

// 04

Infrastructure is code

Every resource is in CDK, CloudFormation or Terraform and is deployed by CI with short-lived credentials. Nothing is set up by hand in a console.
